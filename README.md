1. Project Overview
Forces Academy Faisalabad Learning Management System (LMS) is a full-stack web application developed to support the academy's academic and administrative activities. It provides separate functionality for administrators and students, including student records, courses, timetable management, assignments, fees, notices, attendance, and examination results.
2. Technology Stack
Category	Technology
Frontend	HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3, Bootstrap Icons
Backend	PHP 8.x (Procedural + Prepared Statements)
Database	MySQL
Security	CSRF Token Validation, password hashing (password_hash), session authorization, input sanitization
Deployment	Infinity 
3. Main Features
3.1 Admin Management
•	Dashboard with metrics for enrolled students, courses, pending fees, and notices.
•	Student and course management with CRUD operations.
•	Timetable management with chronological scheduling and custom time slots.
•	Result and notice board for grades and academy-wide notices.
•	Security controls including CSRF protection, secure sessions, password hashing, and prepared statements.
3.2 Student Portal
•	Personalized dashboard for course enrollments, attendance, and fee status.
•	Assignment section for viewing coursework and submitting digital files.
•	Timetable and results sections for class schedules and published examination results.
4. Security
The application uses CSRF token validation, password hashing, session-based authorization, input sanitization, and prepared SQL statements to help protect user accounts and application data.
5. Deployment
The application is deployed live using Infinity Free Hosting, leveraging its native PHP environment and hosted MySQL database engine to manage backend endpoints and data persistence.
